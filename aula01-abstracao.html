Conceito-chave

O que é Abstração?

"Processo mental que consiste em determinar os aspectos gerais de um problema, necessários ao seu entendimento, sem se ater aos seus detalhes mais complexos."

Na programação: abstrair um conceito é limitar-se a entendê-lo e representá-lo numa linguagem de programação, restringindo-se aos detalhes necessários à sua representação.

A mesma coisa, dois olhares

Cada observador abstrai o que precisa

Uma pessoa vê o gato como um bichano fofo. Um veterinário vê o mesmo gato como um conjunto de órgãos: coração, pulmão, rim, estômago. Nenhum dos dois está "errado" — cada um abstraiu o que era relevante para o seu papel.

Na POO: o programador decide, para o problema em questão, quais aspectos do "gato" (ou de qualquer entidade) realmente importam para o sistema.
O produto da abstração

Abstração de Dados x Abstração de Procedimentos

Qual é o produto da abstração na modelagem de um conceito orientado a objetos?

🗂️

Abstração de Dados (T.A.D.)

Definição dos dados (e do tipo de dado) de acordo com o comportamento do objeto. Sua manipulação será feita apenas através de suas operações.

⚙️

Abstração de Procedimentos

Tratar uma função/procedimento como uma operação única e bem definida, mesmo que internamente utilize outras rotinas.

Exemplo mínimo

Uma lâmpada, abstraída

"Uma lâmpada é um objeto que emite luz a uma certa intensidade quando está ligada."

class Lampada: def __init__(self): self.ligada = False self.intensidade = 0 def acende(self, intensidade): self.ligada = True self.intensidade = intensidade def apaga(self): self.ligada = False
Repare: ignoramos filamento, voltagem, tipo de soquete — tudo o que não importa para o problema que estamos resolvendo.
Exercício guiado

Abstração de um celular

Para representar um celular como objeto, primeiro decidimos os dados relevantes; depois, as operações que agem sobre eles.

Dados

  • Estado de funcionamento (on/off)
  • Agenda telefônica (coleção de contatos)
  • Câmera (on/off)
  • Volume (1..30)
  • Wi-Fi (on/off)

Operações

  • ligar(), desligar()
  • addContato(), pesquisar(), excluir()
  • ativarCamera(), zoomIn(), fotografar()
  • aumentarVolume(), diminuirVolume()
  • ativarWifi(), desativarWifi()
Atenção: as operações possíveis sobre o objeto são apenas aquelas que fazem parte da sua definição (interface) — defina o suficiente para as ações que o objeto pode sofrer.

O que vale lembrar sobre abstração

Independe do paradigmaAbstração é um processo mental, útil em qualquer forma de programar.
Introduz um novo tipoA abstração de dados é usada para introduzir um novo tipo de objeto.
Interface bem definidaAs operações possíveis são exatamente aquelas que fazem parte da definição do objeto.
Não se preocupe com o "como"Ao abstrair, não é preciso saber como as operações funcionam internamente — isso vem depois, no Encapsulamento.

Checagem rápida

Abstração de dados ou de procedimento?

"Vamos representar uma Conta com saldo e número, manipulados só por métodos."

Abstração de dados: define-se um novo tipo (Conta) e como manipulá-lo.

"Tratamos calcularFrete() como uma única operação, mesmo usando várias funções internas."

Abstração de procedimento: uma operação única e bem definida esconde os detalhes internos.

"Criamos um novo tipo Ponto3D(x, y, z) com operações somar() e distancia()."

Abstração de dados: um novo tipo abstrato de dado (T.A.D.) foi introduzido.
